脚本用 profile 0–3 训练、profile 4–5 验证。验证段的速度幅值远小于训练段，且
训练与验证没有重复 profile，因此六轮结果只能作为安全检查，不能作为最终的跨轮
模型验证。

- 延迟 ARX 整段自由预测：速度 RMSE 0.0469 rad/s，拟合度 -94.5%，角度 RMSE
  1.222°。负拟合度表示在低动态 profile 4–5 上不如预测其平均速度。
- 滤波速度 ARX 单步预测：RMSE 0.00741 rad/s，拟合度 66.40%。绝对误差小于旧数据
  的 0.00824 rad/s，但验证信号标准差只有约 0.022 rad/s，所以归一化百分比降低。
- 单步模型输入系数由旧数据的 0.012032 变为 0.011945（约 -0.7%），常值项由
  -0.000572 变为 -0.000553；局部输入响应没有显示明显机械劣化。

正式验证需要18轮：前12轮包含每种 profile 两次，后6轮每种 profile 一次，才能在
训练和独立验证中覆盖相同的波形类型。
