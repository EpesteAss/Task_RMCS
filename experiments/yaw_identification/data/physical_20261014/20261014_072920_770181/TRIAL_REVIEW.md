# 固定 Pitch 的 Yaw 反向试采复核（2026-10-14）

- Pitch 机械固定约 +5°，电机命令全程 0 N·m；Yaw 外壳先前实测 30°C，开试前现场报告温度无异常。Yaw 温度遥测仍固定显示 125°C，Pitch CAN0 反馈仍缺失。
- 与上一轮相比 Yaw 未被移动；本轮从上一轮末位启动，配置为 `physical_start_profile: 3`（反向 0.5 Hz）、0.75 N·m、4 s、相对 Arm 中心 ±4.5° 硬行程、±3.6° 提前停激励。
- 实际 Sweep 约 2.10 s，210 个 10 ms 采样。相对本轮起点，激励期间 Yaw 角度范围 −3.45° 至 +0.96°；在 −3.60° 时触发行程提前停激励（`physical_guard_stop=1`），该采样 IMU 角速度约 −0.276 rad/s。Sweep 期间最大绝对 IMU 角速度约 0.304 rad/s，低于 0.4 rad/s 硬阈值。
- 停激励后最终相对本轮起点偏移 −3.77°。`fault=0`、`completed=0`；会话报告 `outcome=stopped`，并确认 OFF、两轴命令 0。退出控制进程时再次出现已知 USB 回调段错误；随后 `pgrep` 确认无 `rmcs_executor` 进程。
- 上轮最终偏移 −2.35°，因此从最初中心累计偏移约 −6.11°。以现场最初确认的左右各至少 8° 净空推算，左侧仅剩约 1.89° 的保守下界。这是由旧净空声明推算，不是新的现场测量。
- 反向激励仍产生较大的负向净滑移，说明在当前姿态/工作区间，单靠该波形不能稳定回到中心。第二轮中断，不能当作完整反向辨识轮次；现有数据不足以验收 Yaw 物理参数。停止继续激励，待现场重新居中、核实两侧实际净空和线缆状态后再设计下一轮。
