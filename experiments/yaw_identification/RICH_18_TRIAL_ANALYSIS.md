# Rich 十八轮正式辨识结果

数据源：`data/20261006_133045_810815/feedback.csv`。18轮全部完成且无拒绝，
profile 0–5 各出现3次。前12轮训练，后6轮独立验证；训练与验证没有共享样本，
且两部分都覆盖全部6种激励。

## 二阶单步模型

采样周期为10 ms，对与控制器一致的12 ms低通速度建模：

```text
vf[k+1] = 1.608590 vf[k] - 0.637960 vf[k-1]
          + 0.00863664 u[k] + 0.00000915
```

模型极点为0.8988和0.7098，均在单位圆内。独立验证速度 RMSE 为
0.00799 rad/s，拟合度为 **90.27%**。

逐 profile 独立验证：

| profile | RMSE (rad/s) | 拟合度 |
|---:|---:|---:|
| 0 | 0.00780 | 84.89% |
| 1 | 0.00877 | 93.68% |
| 2 | 0.00882 | 93.31% |
| 3 | 0.00741 | 49.56% |
| 4 | 0.00744 | 41.28% |
| 5 | 0.00758 | 73.37% |

profile 3–5 的绝对误差与其他轮相近，但实际速度幅值很小，因此归一化拟合百分比
较低。总体90.27%主要由动态更充分的profile 0–2贡献，不能解释成任意时域长度都
具有90%精度。

## 长时自由预测

延迟角度 ARX 模型在完整24 s验证轮上的速度拟合度为20.99%，角度 RMSE 为
1.174°。连续线性和摩擦模型的整段速度拟合度分别为-20.02%和-0.28%。长时误差
反映静摩擦、回差、负载变化和小偏差积分；与10 ms单步预测指标不是同一个问题。

## 安全与重复性

- sweep期间 fault 始终为0，最终OFF正常确认两轴力矩为零。
- yaw速度峰值0.337 rad/s，命令力矩范围 -0.720…0.620 N·m。
- pitch世界角维持在4.46…4.60°。
- pitch温度35…50°C，yaw温度保持31°C，均未触发55°C停机线。
- 相同profile三次运动幅值有变化，特别是低动态profile 4，说明摩擦和热状态仍会
  改变响应；这也是长时自由预测较差的重要证据。
