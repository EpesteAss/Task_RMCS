# Yaw 单一全局迟滞模型候选

目标是用一套方程覆盖此前分别称为 low-angle/high-angle 的运动段，同时描述静止起步和换向。训练使用 12 轮不同角度的 `±1.25 N·m` 纯正弦，以及新增的前两轮 `±0.9 N·m` 交替脉冲。第三轮交替脉冲在参数确定过程中完全留出。

## 统一方程

角度 `theta` 使用电机编码器坐标，单位 rad；`tau` 是日志中的 Yaw 总力矩命令：

```text
theta_dot = omega
0.125 omega_dot = tau + m(theta) - B(theta) omega - 20 z - 0.03 z_dot
z_dot = omega - |omega| 20 z / g(theta, omega)

B(theta) = exp(-0.856163 + 0.583201 cos(theta) + 0.533963 sin(theta))

Fc(theta,omega) = exp(-0.722304
                      - 0.043131 cos(theta)
                      - 0.198093 sin(theta)
                      - 0.106541 tanh(omega/0.05))

Fs(theta,omega) = 1.169343 Fc(theta,omega)
g(theta,omega) = Fc + (Fs-Fc) exp(-(omega/0.18)^2)

m(theta) = 0.033596 + 0.031250 cos(theta) + 0.139453 sin(theta)
```

`z` 是摩擦接触面的内部形变状态。它让同一角度和速度在不同运动历史下产生不同摩擦，因而不再需要人为切换 low-angle/high-angle 两套参数。独立日志没有前序 `z` 时，本报告用 `z0=m(theta0)/20` 初始化。

## 完整轮次验证

第三轮从约 `207.27°` 起步，首脉冲为负向，包含多次换向和零力矩间隔。它未参与参数搜索；试验完整结束，`fault=guard=0`，Pitch、Yaw PID 与前馈命令均为零。统一模型对其完整 4 s 自由预测为：

- 速度拟合度：**67.8%**
- 角度 RMSE：**8.72°**

15 轮数据合并后的速度拟合度为 **69.0%**，速度 RMSE 为 **0.344 rad/s**，角度 RMSE 为 **9.39°**。训练轮次的单轮角度 RMSE 为 `1.37°～15.07°`。它比任一常参数 `J/B/Fc` 在全部数据上的覆盖更均衡，但还没有达到精密前馈所需的整轮预测精度。

## 结论

这是一套覆盖不同角度、方向、起步和换向的统一候选公式。新增内部状态是必要的：三轮连续交替脉冲仅改变首方向和起始角，最终位移分别约为 `-3.20°`、`-23.61°`、`+13.26°`，仅由 `theta/omega/tau` 的无记忆模型不能同时解释。

模型参数仍以日志力矩刻度为条件，输出轴力矩没有独立标定。留出角度误差 `8.72°` 表明该模型适合做物理解释和后续控制仿真的初值，暂不应直接作为高精度物理前馈。后续冻结结构的全局 NARX 模型在新盲测上达到 **87.49% / 2.92°**，见[最终盲测报告](../20261014_global_narx_holdout/REPORT.md)。完整 LuGre 参数和数据分组见 [model.json](model.json)。
