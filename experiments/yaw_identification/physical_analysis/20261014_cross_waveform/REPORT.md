# Yaw 实车辨识：跨波形、幅度和方向验证

时间：2026-10-14 20:40～21:05 CST。Pitch 由现场机械固定，辨识控制器始终给 Pitch 零力矩。下面的 `0.5/1/2 Hz` 是 **4 s Hann 窗余弦力矩**，不是位置闭环正弦。每次 Sweep 前 Arm 以当时 Yaw 为相对零点，CSV 保留绝对编码器角度；没有手动回位。每次会话均完成、回到 OFF，`fault=0`、`physical_guard_stop=0`、Yaw PID/前馈及 Pitch 命令全程为零。结束后又用 `stop-safe.bash` 确认两轴命令为零并退出辨识进程；检查时车上没有 `rmcs_executor`。

## 解释范围

旧模型 `J≈0.117 kg·m²、B≈0.492 N·m·s/rad、Fc≈0.229 N·m` 在 **0.9 Nm、后续方波脉冲** 这一窄工况下能预测四轮新数据，不能作为全波形 Yaw 机械参数或直接用于控制器整定。0.9 Nm 方波移到 121° 起点仍达 90.4%，而相近起点的 0.5 Nm 方波只有 27.1%；幅度相关性比单纯绝对角度更有证据。正向 0.5 Hz 换起点后再次失配，反向 0.5 Hz 与正向结果不同，显示方向和运动历史也可能重要。

本次 Hann 窗使不同频率的负向峰值分别为约 0.497、0.772、0.866 Nm，而正向均到 0.900 Nm；所以表中频率与实际力矩分布共同变化，不能把拟合度差异直接解释成频率响应。方波首脉冲与后续脉冲的历史依赖在前一份报告已有记录。

探索性重拟合也没有消除冲突：用本表除“正向 0.5 Hz 复测”外的全部数据拟合常数 `J,B,Fc,bias` 后，该留出复测的速度拟合度仅约 21.8%、角度 RMSE 约 8.81°；在全部数据上重拟合仍只有约 28.3% / 8.03°。另试了绝对角度回正项、输入变化率项及二阶 ARX；对留出的正向 0.5 Hz 数据均不能可靠自由预测。它们是已看过数据后的探索，不是新的独立验证。

小幅方波单独拟合前两轮，对第三轮的事后时间留出预测为速度拟合度约 81.0%、角度 RMSE 约 0.70°；对应的条件参数 `J≈0.108、B≈1.416、Fc≈0.106` 与大幅方波模型明显不同。用速度相关的非线性阻尼项合并拟合两种方波，对未参加拟合的 0.9/0.5 Nm 方波分别得到约 90.3%/76.2% 速度拟合度，但对正向 0.5 Hz 余弦仍近于 0% 或更低。因此目前可建立**方波局部预测器**，尚无通过正弦验证的统一机械模型；非线性阻尼参数也不应当作已辨识的物理常数。

现有数据支持“简单刚体＋常数摩擦模型不通用”，但**不能唯一判定**是传动间隙、预滑移/摩擦历史、线缆/固定支架负载还是其他未测状态。当前只有电机编码器角度、顶板 IMU 速度与电机力矩反馈；外部旋转件相对固定件的独立角度/力矩尚未同步测量。下一步应先获得该输出侧角度或同步视频，并检查 Pitch 固定件与线缆在 115～141° 区间的负载变化，再针对同一起点交错重复高/低幅方波和正反 0.5 Hz。现有力矩刻度未在 Yaw 输出轴标定，所有 `J/B/Fc` 的绝对单位仍带此前提。

本轮还修正了分析器的元数据字段 `duration_s`：它现在是验证窗口实际长度约 1.99～2.00 s；所有评分数值未变。

## 等峰值纯正弦对照（21:00～21:02 CST）

车载插件增加了起止命令为零、正负峰值均为 0.9 Nm 的纯正弦模式；4 项插件测试和静态预检通过后，正相/反相各完成一轮，均无 fault/guard，结束 OFF、双轴命令零，车上控制进程已停止。源 CSV 分别在 `physical_data/20261014_130051_829626` 与 `130158_204634`。冻结模型在同一 1.3～3.3 s 窗口的拟合度为 85.6% 和 88.4%，说明先前 Hann 窗正向 0.5 Hz 的严重失配不能简单归因于“0.5 Hz”本身；正负峰值不等及运动历史均可能参与。

**整段 4 s 自由预测仍不合格：** 两次纯正弦从 Sweep 起点初始化的速度拟合度分别约 63.3%/58.9%，角度 RMSE 约 20.2°/22.5°。分段评分会在 1.3 s 用实测角度、速度重新初始化，因此不能替代整段模型。这两轮净位移分别约 −21.5°/+30.4°，也说明零均值力矩不保证零位移。目前最可信的是大幅方波和等峰值纯正弦**中段局部动力学**；起始预滑移/历史状态及小幅输入仍待辨识。

## 方波预处理后再测纯正弦（21:04～21:05 CST）

先完成一轮 0.9 Nm 方波，再 OFF、停止进程，立即以当前位置重建纯正弦控制进程并完成一轮。两轮均无 fault/guard，最终 OFF、双轴命令零，车上进程已停止。原始数据分别位于 `physical_data/20261014_130432_374019` 与 `130505_738958`，冻结模型的独立评分见[预处理方波](../20261014_preconditioning_square_holdout/validation.json)、[后续纯正弦](../20261014_pure_sine_after_square_holdout/validation.json)。后续纯正弦的中段速度拟合度为 81.1%、角度 RMSE 2.92°；整段 4 s 角度 RMSE 仍为 19.4°。这种预处理没有解决起始瞬态，继续重复同类激励不足以把局部模型提升为全程机械模型。

## 起始瞬态离线复核

纯正弦三轮的电机编码器角度与 IMU 速度积分之差，整轮 RMSE 为 0.10～0.33°；电机速度积分与编码器角度之差为 0.10～0.14°。因此整段预测偏差约 19～23°，不能由这些通道的普通积分误差解释。首轮在 0.25 s 时命令约 +0.65 Nm，实际角度仅约 +0.1°；冻结的运动模型此时已预测 +1.2°，到 1 s 预测 +36.5° 而实际约 +13.2°。反相轮也有类似起步迟滞。

在不改冻结运动参数的条件下，仅用第一轮正向纯正弦选取一个静摩擦脱离阈值的[可复现试算](static_friction_check.py)，条件阈值约 0.86 Nm；[结果](static_friction_check.json)显示第一轮整段角度 RMSE 仍有 14.9°，两轮未参与阈值选择的纯正弦为 15.9°、14.7°。单一静摩擦阈值不足以解释起始瞬态。此为探索性诊断，不是新增的合格辨识参数。当前没有同步输出侧角度或输出轴力矩；若暂时无法拍摄固定机位视频，应保留原始数据与局部模型结论，待取得独立测量后再判别机械原因。

## 高负载运动段结果（21:16～21:20 CST）

现场确认机械转动无阻碍、负载偏重后，提高纯正弦峰值至 1.25 Nm，并完成 0.5、1、2 Hz 与反相 0.5 Hz。频率响应辨识得到条件参数 `J=0.1238 kg·m²、B=0.2753 N·m·s/rad、Fc=0.2197 N·m`；三个正相频率独立给出的有效惯量范围为 0.1161～0.1299 kg·m²。只用正相数据拟合后，对反相 0.5 Hz 留出的速度增益误差为 −4.15%，相位误差为 +7.71°。详见[高负载频率响应报告](../20261014_high_amplitude_frequency_response/REPORT.md)。该模型用于已运动的周期响应；低幅起步仍需单独处理。
