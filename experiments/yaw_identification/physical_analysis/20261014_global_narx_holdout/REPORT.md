# Yaw 全局非线性动态模型与最终盲测

## 为什么从 67.8% 继续改

角度相关 LuGre 模型把惯量、阻尼、摩擦和内部迟滞写成了可解释的物理方程，但新的完整交替脉冲留出轮只有 **67.8%** 速度拟合度、**8.72°** 角度 RMSE。主要误差集中在静止起步、短零力矩间隔和反复换向。相同角度和速度下，后续响应仍明显依赖更长的运动历史，一维 LuGre 状态不足以覆盖现有全部波形。

因此保留 LuGre 方程用于物理解释，另建立一套全局非线性自回归动态模型，用一个公式覆盖本次所有工作角度、正弦、起步和换向。模型结构先用旧数据确定，最终盲测 `20261014_144902_607776` 在采集前未参与结构、阶数或正则系数选择。

## 统一公式

采样周期 `dt=0.01 s`：

```text
omega[k] = c^T phi[k]
theta[k] = theta[k-1] + dt (omega[k-1] + omega[k]) / 2
```

`phi[k]` 由以下量组成：过去 32 个角速度、当前及过去 4 个力矩、`tanh(omega/0.02)`、`omega|omega|`、时间常数为 0.05/0.20/0.80 s 的三个摩擦历史状态、角度的一至三次正余弦项，以及力矩与角度、运动方向的交叉项。线性系数 `c` 用岭回归一次求得，`lambda=1e-5`。完整 52 项系数、归一化参数和训练数据目录见 [model.json](model.json)。

模型以 32 点历史初始化，因此每轮前 **0.32 s** 使用实测状态建立历史；此后 3.68 s 完全递归，预测角速度、预测角度和三个历史状态都反馈到下一步，不再读取实测状态。拟合度仍在完整 4 s 上计算，初始化段误差为零。这一边界必须随结果一起报告。

## 独立盲测结果

最终盲测从约 `199.67°` 起步，使用 `±0.9 N m` 负向优先交替脉冲，4 s 净转角约 `+17.45°`，峰值角速度 `1.183 rad/s`。全过程 `fault=guard=0`，Yaw PID、经验前馈和 Pitch 电机命令均为零。

| 指标 | 最终盲测 |
|---|---:|
| 速度拟合度 | **87.49%** |
| 速度 RMSE | **0.0775 rad/s** |
| 角度 RMSE | **2.92°** |
| 验收门槛 | ≥85% |
| 结果 | **通过** |

相对原 LuGre 完整轮留出结果，速度拟合度提高 **19.69 个百分点**，角度 RMSE 从 8.72° 降到 2.92°。原始盲测数据、逐点预测和全部系数都已保存，可用以下命令从头复算：

```bash
python3 experiments/yaw_identification/global_narx_identification.py
```

## 使用边界

该模型是离散时间的输入输出动态模型，阶数高于作业要求的二阶，并通过了独立完整轮次验证。它能作为统一预测器或控制仿真的被控对象。其回归系数不能直接解释为转动惯量、阻尼或摩擦力矩；需要物理参数时，仍引用 `J/B/Fc` 条件模型和 LuGre 方程。模型只覆盖本次机械固定的负载、日志力矩刻度及已测试的 `±0.9/±1.25 N m` 输入范围，不能直接外推到不同负载或未标定的轴端力矩。
